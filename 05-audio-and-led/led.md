# Часть 3 — LED: как работает и формат файлов

## 1. Железо и управление
- Индикатор Станции Лайт — **3 RGB-светодиода** (подтверждено форматом паттернов:
  в каждом кадре ровно 3 значения цвета).
- Управляет LED подсистема `maind`; отдельный вход — **`led_util`** (симлинк → `maind`):
  ```
  led_util <путь/к/pattern.led>
  ```
  проигрывает указанный паттерн на светодиодах. В штатной работе паттерны проигрывает
  `platformd` в ответ на состояния (слушает/думает/говорит/ошибка/таймер/звонок…).
- Рядом в железе — ёмкостные кнопки Cypress `CY8CMBR3` (отдельный узел, `irq/33-cy8cmbr3`).

## 2. `ledpatterns/*.led` — формат (текстовый, покадровый)
33 файла состояний: `alice_listening/speaking/thinking`, `alice_pro_*`,
`bluetooth_*`, `call_*`, `error`, `timer`, `volume`, `update_applying`,
`connecting_to_network`, `iot_discovery`, `notification_*`, `player_*`, `qc`, `soundinit`,
`configure`, `data_reset_progress`, `intonation_spotting` и др.

Структура файла:
```
[gammacorrection]          # необязательный флаг: применять гамма-коррекцию
[loop]                     # необязательный флаг: зациклить анимацию
<RGB0> <RGB1> <RGB2> <dur>  # кадр: цвет каждого из 3 LED (hex RRGGBB) + длительность, мс
<RGB0> <RGB1> <RGB2> <dur>
...
```
Пример (`alice_speaking.led`, 25 кадров по 40 мс, `loop`) — сине-фиолетовое «дыхание»:
```
loop
6c0fff 6c0fff 6c0fff 40     # ярко (R=6c G=0f B=ff — фиолетовый)
5b0dd7 5b0dd8 5b0dd8 40     # гаснет…
...                          # до минимума и обратно к 6b0fff — пульсация
```
`volume.led` — зелёный ramp с шагом 1000 мс. Длительность в последнем столбце —
время показа кадра (мс).

## 3. `ledconfigs/*.json` — цветокоррекция (НЕ «цвета»)
Файлы `beige/green/pink/purple/red/yellow.json` — это **матрицы цветокоррекции 3×3**
(калибровка гаммы/гамута физических LED), а не палитра:
```json
{ "type": "matrix",
  "matrix": [[ 0.782,-0.092,-0.027],
             [-0.016, 1.112,-0.0004],
             [ 2.8e-19,0.033, 1.104]] }
```
Матрица умножается на желаемый RGB, чтобы на конкретной партии светодиодов цвет выглядел
корректно. Имя файла — целевой профиль/оттенок, содержимое — коэффициенты коррекции.

## 4. Демонстрация (сделано)
Создан свой паттерн и проигран на устройстве:
```bash
cat > custom.led <<'EOF'
gammacorrection
ff0000 ff0000 ff0000 600
00ff00 00ff00 00ff00 600
0000ff 0000ff 0000ff 600
ffffff ffffff ffffff 600
EOF
adb push custom.led /tmp/custom.led
adb shell "LD_LIBRARY_PATH=/system/vendor/quasar/libs /system/vendor/quasar/led_util /tmp/custom.led"
```
`led_util` запустился без ошибок и проиграл красный→зелёный→синий→белый (по 600 мс).
Без флага `loop` паттерн проигрывается один раз, после чего `platformd` возвращает
штатную индикацию. Обратимо, систему не меняет.
